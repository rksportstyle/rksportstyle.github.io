# RK Sport Style — catálogo digital

Site estático (HTML, CSS e JavaScript puros, sem frameworks). Pode ser hospedado em qualquer serviço de páginas estáticas com HTTPS (GitHub Pages, Netlify, Cloudflare Pages).

- `index.html`: página e dados do catálogo.
- `app.js`, `app.css`: código e estilo.
- `img/c/`: fotos das camisas (WebP + JPG para aparelhos antigos).
- `img/s/`: miniaturas agrupadas (WebP + JPG).
- `fonts/`: fontes (licença SIL OFL).

Painel: abra o endereço do site com `#admin` no final. No GitHub Pages, ele pede uma chave de acesso do GitHub com permissão de escrita só neste repositório. A chave fica apenas no aparelho de quem administra.
